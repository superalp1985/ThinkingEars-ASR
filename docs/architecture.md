# 实现说明

## 数据流

```text
已有 ASR 文本
    -> 可选的显式纠错规则
    -> 已知词保护 / 唯一同音热词匹配
    -> 可选的停顿标点
    -> 增强文本

16 kHz 单声道音频
    -> 可选的 sherpa-onnx Paraformer
    -> 上述文本增强
    -> 文本 + 8 项语音指标
```

`core.py` 从 AI开放剧本模拟器 V5 的 `asr_core.pyx` 提取。
原文件可按 Python 解释执行，这个发布版无需 Cython 或预编译 Windows 扩展。

## 词库保护

运行词库由原 `master_dict.json` 的全部键无损导出。
标准库 `gzip` 和 `json` 负责解压及解析，通过包资源 API 随安装包加载。
内存中的词条使用不可变集合，多实例共享内置集合。
完整标注词库作为独立压缩资源保存，清单记录原始文件哈希用于核验。

先标记已知词与显式纠错目标词的保护范围，最长 10 个字符。
保护范围内部不会启动热词替换，候选替换也不能改动保护范围中的字符。
其他位置按最长连续中文片段优先扫描，只在等长热词的无声调拼音唯一时替换。
英文、空格和标点不会进入拼音候选，避免替换时丢失混合语种文本。
同音候选多于一个时保持原文。
这是一种保守规则，已知词本身被识别错为另一个已知词时，通常需要显式规则或更强的上下文判断。

默认不启用游戏领域的强制替换规则。相关配置放在 `examples/`，供调用方自行选择。
`set_hotwords()` 构造新映射后在锁内替换；`enhance()` 在同一锁内运行。

## 音频和指标

输入约定为 16,000 Hz、单声道、有限浮点波形，通常归一化到 [-1, 1]。
API 不根据波形猜测采样率，调用方需要在传入前完成重采样。

| 字段 | `raw` 含义 |
| --- | --- |
| `avgVolume` | 全段 RMS，线性幅值 |
| `peakVolume` | 最大绝对幅值 |
| `speechRate` | 文本非标点字符数 / 音频秒数 |
| `pauseFrequency` | 低能量 80 ms 帧数 / 秒，并非独立停顿事件数 |
| `pauseDuration` | 低能量帧占全部分析帧的比例，并非毫秒 |
| `voiceVariation` | 各帧 RMS 的标准差 / 全段 RMS |
| `endingRise` | 自相关法估计的尾部与头部基频之差，Hz |
| `duration` | 秒 |

`score` 保留原实现的 1 至 10 归一化启发式分值，未经临床或心理学验证。
这些指标不输出情绪类别。

麦克风路径使用能量阈值分段，在停顿时提交片段，再合并最终文本。
这属于离线模型的分段调用。模型文件、音频驱动和麦克风权限由运行环境提供。
模型初始化与解码分别串行执行。上一录音线程完成之前不接受新录音。
解码失败会保留待处理音频并写入错误状态，供调用方检查。
`stop()` 最多等待录音线程 1.5 秒，较慢设备可继续检查 `snapshot()["final"]`。

## 发布整理

- 保留原作者和原项目来源。
- 添加可独立安装的 Python 包与命令行。
- 让文字增强独立于模型和麦克风依赖。
- 将模型目录、热词、纠错规则、保护词库改为可配置。
- 修复保护词内部继续匹配的风险，并对同音热词歧义保持原文。
- 默认保留英文空格和已有标点；规则断句需要显式启用。
- 将全部词条和原始标注分别无损压缩，随仓库提供。
- 延续原项目非商业限制。
